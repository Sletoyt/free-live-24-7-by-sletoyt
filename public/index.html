📖 Beginner Guide — शुरू से अंत तक कैसे चलाएं (Step-by-Step)

Follow these 4 simple steps to connect OBS Studio, set up automatic scene switching, and stream 24/7 in both 16:9 and 9:16 at the same time.

STEP 1

🎥 OBS Studio को Tool से Connect करें (Failed to Connect Fix)

अगर आप GitHub Codespaces चला रहे हैं, तो .app.github.dev:1935 काम नहीं करता क्योंकि GitHub पोर्ट 1935 ब्लॉक रखता है। इसलिए यह टूल अपने आप एक Public RTMP Tunnel URL बनाता है:

OBS Server URL: Connecting tunnel...
  • अपने PC के OBS Studio में Settings → Stream खोलें।
  • Service में Custom... चुनें।
  • Server में ऊपर दिया गया OBS Server URL पेस्ट करें (अगर रियल VPS है तो rtmp://VPS_IP:1935/live भी डाल सकते हैं)।
  • Stream Key में अपने चैनल की Ingest Key (जैसे live_sleto) डालें और Start Streaming दबाएं!
STEP 2

🎨 3 प्रकार के Automatic Scenes समझें

Dual Studio टैब में आपको 3 तरह के सीन मिलते हैं जो अपने आप काम करते हैं:

  • 🟢 1. Default Scene (अधिकतम 1): जब OBS से आपकी Window + Voiceover लाइव आ रही हो और स्क्रीन पर कोई ट्रिगर कलर न हो, तब यही मुख्य सीन चलता रहेगा।
  • 🌸 2. Color-Detect Scene (Multiple): इसमें आप कोई भी रंग (जैसे Pause स्क्रीन का रंग या काला रंग #000000) सेट कर सकते हैं। जैसे ही पूरी स्क्रीन पर वह रंग आएगा, लाइव अपने आप इस सीन पर स्विच हो जाएगी, और रंग हटते ही वापस Default Scene पर आ जाएगी!
  • 📡 3. Network Error Scene: जब आपके PC के OBS से सिग्नल आना बंद हो जाए (इंटरनेट कट जाए), तो यह सीन अपने आप स्क्रीन पर आ जाएगा और सिग्नल वापस आते ही Default Scene चालू हो जाएगा।
STEP 3

📁 Cloud Files में BG Music और Logo अपलोड करें

अपने सीन को सुंदर बनाने के लिए Cloud Files टैब का उपयोग करें:

  • Cloud Files टैब खोलें और अपना Background Music (.mp3), Channel Logo (.png) या Pause Video (.mp4) अपलोड करें।
  • अब Dual Studio में किसी भी Scene को चुनें और दाईं तरफ ＋ Source बटन दबाकर अपना Logo, Video या BG Music जोड़ें।
  • आप किसी भी फाइल को कभी भी वापस अपने फोन या PC में Download भी कर सकते हैं।
STEP 4

📺📱 एक साथ 16:9 और 9:16 Dual Live चलाएं

एक ही सीन के सोर्स दोनों रेशियो में दिखते हैं, लेकिन दोनों की पोजिशन अलग-अलग सेट की जा सकती है:

  • Dual Studio में बाईं स्क्रीन 16:9 Landscape है और दाईं स्क्रीन 9:16 Vertical Shorts है।
  • माउस से पकड़कर किसी भी लेयर को 16:9 में अलग जगह और 9:16 में अलग जगह सेट करें, फिर 💾 Save Scenes दबाएं।
  • Channels टैब में ⚙️ Stream Keys पर क्लिक करके अपनी 16:9 YouTube Key और 9:16 Shorts Stream Key डालें।
  • अब ▶ Start Dual Playout या 🚀 Go Live Dual दबाएं — दोनों लाइव एक साथ शुरू हो जाएंगी!
